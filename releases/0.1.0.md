# 0.1.0

## Added

- Native .NET MAUI Android planner with Home, Recurring and Lists navigation, using teal and blush colors.
- Persistent General/custom lists and dated tasks, with editing, completion, completed-task popups and Undo.
- Daily, selected-weekday and selected-day/selected-month routines with pause/resume and independent completion for each date.
- Shared month/week calendar for upcoming tasks and routine occurrences.
- Offline atomic JSON storage, previous-save backup, input validation, and protected handling of unreadable data.
- Core regression tests, reusable Android regression cases, and a build helper for Windows checkout paths containing non-ASCII characters.
- To-do list tasks for lists, dates and recurring routines, with editable subtasks, completed/total progress and a popup for checking items. Parents complete automatically and reopen when an item is unchecked; recurring progress stays separate for each date.
- Android launcher widgets for tasks remaining today (1×1), completed/total (2×1), and pencil task creation (1×1). Count widgets open Home and show a checkmark when all tasks are done; the pencil opens today’s task form. Saved changes refresh all placed copies.

## Notes

- Initial development APK; publishing and distribution signing are separate.
- Existing planner files upgrade on their next successful save to schema version 2, preserving ordinary tasks and completion history. Older app builds cannot read the upgraded format.
- Device interaction and persistence checks cover a physical Android 16 phone. Other Android versions, screen sizes, and enlarged system text need further device coverage.
- Widget placement, empty/partial/all-done states, save/complete/Undo/delete refresh and cold/warm navigation were checked on an API 36 emulator. Overnight/boot timing, large fonts, older APIs and OEM launchers still need device coverage; Android may defer background refresh while idle.
