# 0.1.0

## Added

- Local crash reports collect managed call stacks and available Android exit
  records, with bounded retention, report viewing and user-initiated ZIP sharing.
  Reports stay on the phone until shared; planner files are excluded. System
  traces can contain diagnostic data and capture remains best-effort.
- Native .NET MAUI Android planner with Home, Recurring and Lists navigation, using teal and blush colors.
- Persistent General/custom lists and dated tasks, with editing, completion, completed-task popups and Undo.
- Daily, selected-weekday and selected-day/selected-month routines with pause/resume and independent completion for each date.
- Shared month/week calendar for upcoming tasks and routine occurrences.
- Offline atomic JSON storage, previous-save backup, input validation, and protected handling of unreadable data.
- Core regression tests, reusable Android regression cases, and a build helper for Windows checkout paths containing non-ASCII characters.
- To-do list tasks for lists, dates and recurring routines, with editable subtasks, completed/total progress and a popup for checking items. Parents complete automatically and reopen when an item is unchecked; recurring progress stays separate for each date.
- Android launcher widgets for tasks remaining today (1×1), completed/total (2×1), and pencil task creation (1×1). Count widgets open Home and show a checkmark when all tasks are done; the pencil opens today’s task form. Saved changes refresh all placed copies.
- Required task titles that fit two lines and optional descriptions with no length limit. Tapping a title opens a read-only popup with its description and date/list or recurrence schedule; the app remains visible behind it. Close, outside tap and Back dismiss the popup. Checklist icons and progress controls retain their interactive checklist action.
- Optional silent daily notifications with a remaining-task preview, live completion/Undo updates, the app's teal/blush styling and permission-aware local-midnight scheduling. Home's bell opens settings; sticky mode restores dismissed summaries and keeps an All done state until the next day.

## Changed

- To-do lists now open in a spacious checklist page with clear progress, larger item rows and softer completed states. Checking items keeps the scroll position. Numbered editor rows support keyboard Next, and unused new blank rows no longer prevent saving.

## Fixed

- Rapid Add task and other navigation taps open one editor. Closing, saving,
  deleting and Android Back share a navigation guard, preventing duplicate
  dismissals and the recorded empty-modal-stack crash. Nested editors return to
  their parent, and widget shortcuts wait for in-flight editor operations.

## Notes

- Initial GitHub release with a Release-configuration APK for ARM64 and x86_64.
  The APK uses the existing Android development signing key; store distribution
  and production signing are not configured.
- Release is recommended for ordinary phone use to avoid the installed Debug
  runtime's reported concurrent assembly-loading crash. Navigation stress tests
  and 20 cold-start/background/resume cycles passed on an API 36 emulator;
  this does not establish a fix for every possible exit or physical-device stability.
- Existing version 1 and 2 planner files upgrade on their next successful save to schema version 3, preserving tasks, subtasks and completion history. Short legacy descriptions become titles; long text is preserved as the description with a whole-word title prefix. An oversized first word uses a Unicode-safe prefix. Older app builds cannot read the upgraded format.
- Device interaction and persistence checks cover a physical Android 16 phone. Other Android versions, screen sizes, and enlarged system text need further device coverage.
- Widget placement, empty/partial/all-done states, save/complete/Undo/delete refresh and cold/warm navigation were checked on an API 36 emulator. Overnight/boot timing, large fonts, older APIs and OEM launchers still need device coverage; Android may defer background refresh while idle.
- Task title validation, description persistence and clearing, popup dismissal, long-description scrolling and completed-task details were checked on an API 36 emulator. The project-owned Managed suite preserves existing data and removes its own fixtures; large-font and older-device layouts remain manual coverage.
- Checklist keyboard entry, completion/reopening, edit cancellation, saved item changes and long-list scroll stability were checked on an API 36 emulator. Physical-phone and enlarged-text checklist layouts remain manual coverage.
- Notification activation, exact-alarm permission handling, unsecured lock-screen display/expansion, completion/Undo, sticky swipe restoration, tap navigation, normal dismissal persistence and cancellation were checked on an API 36 emulator. Local-midnight/DST calculations have core regression coverage; actual overnight delivery, reboot and OEM privacy/background behavior still need device coverage. Android notification and alarm permissions, lock-screen settings and force-stop constrain delivery and persistence.
